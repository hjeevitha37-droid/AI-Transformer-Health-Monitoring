# AI-Based Transformer Health Condition Monitoring

## Run on Windows / VS Code
1. Extract the ZIP and open this folder in VS Code.
2. In the terminal run:
   `python -m venv .venv`
   `.venv\Scripts\activate`
   `python -m pip install -r requirements.txt`
3. Generate the simulated dataset: `python generate_dataset.py`
4. Train and evaluate models: `python train_model.py`
5. Start the dashboard: `python -m streamlit run app.py`

## Included
- Simulated dataset with load, ambient/oil temperature, voltage, oil level, moisture, vibration and H2 indicator.
- Random Forest and Gradient Boosting comparison.
- Accuracy, weighted F1, classification report, confusion matrix and feature importance.
- Streamlit interface for interactive predictions.

## Critical limitation
Dataset and target labels are synthetic and generated by a simple rule. Metrics only measure agreement with that rule on a held-out synthetic split. This is an educational demonstration, not a validated predictive maintenance system. Do not use it for real transformer decisions. Replace with a documented, permissioned, validated dataset before making engineering claims.
